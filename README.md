# MSU Lift Tracker

Description: Our app is designed to help MSU sports teams track who has the strongest athlete, who needs more work, and keep track of school records.   We hope our app is helpful to the teams and can help make decisions on how to continue gaining strength.
Features:
1. Track lifts between teammates
2. Show progress as inputs are placed in the app
3. Store data and plot different graph types based on what the user wants to see (bench comparisons, pound-for-pound strength, overall heaviest weights, etc.)
4. Add more features as requested or needed
